# ATLAS3D

3D uydu haritası ve GPS takip prototipi.

Cloudflare Pages ayarları: Framework preset **None**, build command **boş**, output directory **/**.

İlk açılışta Mapbox public token (pk.) sorulur ve yalnızca tarayıcının yerel depolamasına kaydedilir.

GPS için HTTPS ve konum izni gerekir. Rakım değeri, yol veya GPS rakımı değil, harita arazi modelinin tahminidir. Gerçek eğim analizi sonraki sürümdedir.
